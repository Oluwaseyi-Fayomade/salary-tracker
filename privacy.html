What is stored?

  • In this browser: game progress, nickname and score, salary and budget choices, priorities, spending entries and notes, imported transaction details, and a cached exchange-rate table. Browser storage is not encrypted by this app; anyone with access to this browser profile or device may be able to view it.
  • If you configure and choose cloud sync: the plan and game snapshot you submit, and the email/account details managed by the configured Supabase project.
  • If bank linking is enabled by the site owner and you explicitly consent: the selected bank connection status and transactions requested through Mono. The prototype imports transactions for budgeting and does not make payments.

Where and why?

The core planner stores data in this device’s browser local storage. The site owner does not receive it through the static app. A user-initiated cloud save sends a snapshot to the site owner’s configured Supabase project. Currency conversion requests the provider’s public rate table; salary amounts are converted in the browser and are not sent to the rate provider. Google Fonts and the Supabase JavaScript package may be loaded from their respective providers when the page or optional cloud feature is used.

Hosting provider, project region, retention periods, and any operational logs depend on the site owner’s deployment and must be documented by the operator before public launch.

Your choices and deletion

Downloaded JSON backups are not encrypted by this app. Store them somewhere private and delete copies you no longer need. You can download or restore a backup, delete data saved in this browser from the app, delete a cloud snapshot, or request deletion of the cloud account and its associated records when cloud sync is configured. Removing local data does not delete a cloud copy. Deleting the cloud account does not erase a backup file you downloaded or data held by third-party providers under their own policies. Disconnecting a linked bank keeps transactions already imported locally.

To exercise privacy rights or raise a concern, contact the operator using the contact above. You may also contact the Nigeria Data Protection Commission. Applicable rights and lawful bases depend on the operator, purposes, and jurisdiction; this draft does not claim legal compliance.
